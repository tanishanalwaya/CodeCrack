# CodeCrack 🧠

A structured collection of LeetCode problem solutions focused on improving problem-solving, algorithms, and data structures.

## 📂 Repository Structure

Solutions are organized by problem number and slug:

`<problem-number>-<problem-slug>`

Example:

`0001-two-sum`

Each directory contains the corresponding solution file.

## 🎯 Purpose

This repository serves as a centralized record of solved coding problems and provides an organized reference for algorithmic practice.
